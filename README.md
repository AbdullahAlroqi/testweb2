# نظام الولاء COFFLOW ☕

نظام ولاء ذكي لمقهى COFFLOW يسمح للعملاء بجمع نقاط الولاء والحصول على مكافآت مجانية.

## المميزات ✨

- **للعملاء**: تسجيل حساب، جمع الأكواب، الحصول على أكواد مجانية
- **للموظفين**: إضافة أكواب للعملاء، التحقق من الأكواد
- **للإدارة**: إدارة الموظفين والعملاء، تعديل الإعدادات، مراقبة العمليات
- **واجهة متجاوبة**: تعمل بشكل ممتاز على الجوال والمتصفح
- **تصميم عربي**: واجهة باللغة العربية بالكامل

## المتطلبات 📋

- Python 3.8 أو أحدث
- pip (مدير الحزم)

## التثبيت والتشغيل 🚀

### 1. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق

```bash
python app.py
```

سيعمل التطبيق على: `http://localhost:5000`

## الاستخدام 📱

### للعملاء:
1. سجل حساب جديد من صفحة التسجيل
2. اشتري قهوتك المفضلة من المقهى
3. سيضيف الموظف كوباً لحسابك
4. عند إكمال العدد المطلوب، ستحصل على كود مجاني
5. أظهر الكود للموظف للحصول على كوب مجاني

### للموظفين:
1. سجل دخول بحسابك
2. ابحث عن العميل بالاسم أو رقم الجوال
3. أضف كوباً عند كل عملية شراء
4. تحقق من أكواد العملاء عند طلب الكوب المجاني

### للإدارة:
1. سجل دخول بحساب الإدارة
2. أضف موظفين جدد
3. راقب العملاء والعمليات
4. عدّل الإعدادات (عدد الأكواب، الألوان، الشعار)

## قاعدة البيانات 💾

يستخدم النظام SQLite ويتم إنشاء القاعدة تلقائياً عند أول تشغيل.

الجداول:
- **users**: العملاء والموظفين والإدارة
- **coupons**: الأكواد المجانية
- **transactions**: سجل العمليات
- **settings**: إعدادات النظام

## التخصيص 🎨

يمكنك تخصيص النظام من خلال لوحة تحكم الإدارة:
- تغيير عدد الأكواب المطلوبة
- تغيير الألوان
- رفع شعار مخصص
